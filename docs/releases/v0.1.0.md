# ProjectDeck v0.1.0

第一个可日常使用的版本：**本机所有 AI 产物项目的总目录 + 总开关 + 一个永远不变的本地入口。**

## 亮点

**给每个项目一个永远不变的本地入口。** 项目真实端口在 5173 / 5174 之间怎么跳，`http://127.0.0.1:9100` 和 frpc 隧道都不用改。

```
frpc / 浏览器 → :9100（ProjectDeck 监听，固定）
                     └→ 每次连接时解析 → :5173 / :5174 / 随便
```

## 功能

- **扫描**：多根目录、嵌套仓库、monorepo；扫描过程有实时进度（已扫描目录、已收录、已过滤、最近发现的项目），结束后给出可解释的报告（根目录、规则、过滤原因）
- **只收录能跑的项目**：纯文档、无启动入口的包会被过滤并说明原因
- **目录**：技术栈、README、版本、路径、git 分支与最近提交、创建时间
- **启停**：识别 `npm run dev`、`python3 app.py`、`go run .` 等入口；仪表盘卡片和列表都能直接启停
- **实时日志**：SSE + ANSI 颜色，自动滚动；停止后仍可回看
- **启动失败说清楚**：端口被占用 / 缺依赖 / 命令不存在 / 运行时没装 / 没权限，直接标红，不再假装成功
- **端口回收**：启动前清掉「工作目录在本项目里」的旧进程（不只看声明端口），停止后再扫一遍残余；外部进程绝不误杀
- **固定端口映射**：一键分配 9100–9199，可指定转发到哪个端口（多端口项目选前端而不是 API），映射持久化在 `config.json`，目录搬家按 path 认回来
- **一键安装依赖**：`npm/pnpm/yarn/bun install`，输出进同一个终端
- **中英双语**，`?lang=zh|en` 可强制切换

## 工程

- 30 个自动化测试（单元 + API 集成）+ 7 个真浏览器 E2E，CI 全绿
- 测试用临时状态目录和 fixture 项目，不会碰你真实的 `~/.projectdeck`
- 设计文档、AGENTS.md、CONTRIBUTING.md、llms.txt 齐全

## 快速开始

```bash
npm install
npm run build
npm start        # http://127.0.0.1:4321
```

## 已知限制

- 目前只支持 macOS / Linux（依赖 `lsof`）
- Swift / 小程序这类没有命令行启动入口的项目只能查看，不能启动
- MCP server 尚未提供（v0.2）
